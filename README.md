# Aurora Conifer · 粒子圣诞树

一棵由数千枚发光粒子逐点拼出的圣诞树：可以拖动自由观察、粒子带拖尾、灯与松针各自闪烁，伸手去碰它们会躲开，松手后整棵树慢慢回到原样。

**在线预览** —— https://minnorursa.github.io/particle-christmas-tree/

![预览](preview.jpg)

## 交互

| 操作 | 效果 |
| --- | --- |
| 拖动 | 自由旋转视角（松手后有惯性，静置 3 秒缓缓接回自转） |
| 滚轮 / 双指捏合 | 拉近推远 |
| 按住 | 粒子被指尖推开并绕行；**同时闪烁停止** |
| 松手 | 粒子以阻尼弹簧回到原位，约 1 秒后闪烁重新浮起 |
| 双击 / 空格 | 整棵树向外绽开再聚拢 |
| `F` | 手动开关闪烁 |
| `?hq=1` | 关闭自适应降级，强制满画质 |

## 特性

- **约 5800 枚粒子**在伪 3D 空间中构成锥形冷杉，随视角旋转产生真实的纵深与视差
- **自由视角**：拖拽改 yaw / pitch、滚轮改焦距，松手带惯性滑行，静置后无缝接回自转
- **运动拖尾**：树体渲染在独立离屏层上，每帧按指数衰减抹淡，移动的粒子自然拖出光丝
- **短促闪烁**：随机粒子在 85~185 ms 内亮到晃眼再迅速熄灭，灯光整体偏快偏亮、松针偏慢偏淡
- **指尖避让**：屏幕空间斥力 + 切向绕行 + 弹簧回位；按住时闪烁冻结，松手后延迟恢复
- **灯与叶的区分**（刻意轻微）：灯的弹簧更硬、轨迹更长、彗尾更明显、闪得更凶；松针更软、更沉、更含蓄
- **两级泛光**：4 倍与 12 倍降采样回合成，得到柔和的辉光与光晕，而非糊成一片的白
- **拟真景深**：远处的粒子更大更暗（散景），近处更锐利
- **入场动画**：粒子从散开的星尘中汇聚成树
- **自适应画质**：持续掉帧时先降一级泛光，再降一半粒子，且只降不升，避免画面抖动
- **单文件、零依赖**（除标题字体走 Google Fonts，失败时回退到系统衬线体）
- 尊重 `prefers-reduced-motion`

## 技术要点

- 纯 Canvas 2D，无 WebGL、无第三方库；所有辉光用预渲染的 64px 径向渐变贴图缩放绘制，配 `globalCompositeOperation = 'lighter'` 做加法混色
- 树体是**面积加权采样**的锥面 + 10 层"裙边"，裙边用 `sin(πt)` 的钟形曲线在层界连续过渡，因此俯瞰不会露出同心圆环
- 20% 的粒子落在解析螺旋线上，形成一道缠绕的灯带
- 拖尾层用 `destination-out` 按 `1-(1-base)^(dt·60)` 衰减，帧率无关
- 避让是屏幕空间的：斥力 `(1-d/R)²` 叠加切向分量，再用 `k` / `damp` 两个参数决定回位手感
- 泛光：每帧把主画布降采样到 1/4 与 1/12，再以加法叠回；两级叠加撑开光域
- 调试接口：`window.__tree`（`state` / `cam` / `flash` / `seek(t)` / `step(dt,n)` / `touch(x,y)` / `release()` / `burst()`）
